# Changelog

## 2.0.0.dev0 — AION (development, 2026-11-10)

- Introduce AION / Recursive Identity Lab as the project's new working name.
- Add a separate label-symmetric engine with nonlinear feedback, bounded recent evidence and arbitrary symbol candidates.
- Add explicit unresolved ties, persistent acquisition and revocable commitment.
- Add private seeded sampling, JSON checkpoints, streamed trajectories and source/input fingerprints.
- Add matched-input controls, frequency baselines and switch/silence experiments.
- Add standard-library tests, installable packaging, a CLI and a Python 3.10–3.13 CI workflow.
- Document measured results and the gap between symmetric selection and demonstrated endogenous identity.

The original `recursive_identity_dynamics/` files, repository address, license and historical citation are preserved. This is not a published v2 release and does not claim feature parity with the legacy goal/graph machinery.
